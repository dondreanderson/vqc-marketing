# VU-QC Marketing Site

**AI-powered construction intelligence for global infrastructure, energy, utility, and commercial construction teams.**

> *Catch It Before You Build It.*

## Site Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero, platform overview, modules preview, ROI calculator |
| Platform | `platform.html` | Platform architecture and workflow overview |
| Modules | `modules.html` | Detailed module breakdown (Contract, Design, RFI, etc.) |
| Surety & Bonding | `surety.html` | Surety intelligence dashboard and partner features |
| AI Agent | `ai-agent.html` | AI assistant capabilities and usage analytics |
| Pricing | `pricing.html` | Pricing tiers, feature comparison, ROI calculator |
| Use Cases | `use-cases.html` | Industry-specific use cases and workflows |
| Global Support | `global-support.html` | Multi-language, multi-currency, regional support |
| Resources | `resources.html` | Blog, guides, documentation, webinars |
| Contact | `contact.html` | Demo request, pilot signup, contact form |

## Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, responsive breakpoints, Inter font
- **Vanilla JavaScript** — No framework dependencies
- **Vercel** — Static hosting with edge CDN

## Local Development

```bash
python3 -m http.server 8000
# Then open http://localhost:8000
```

## Deployment

This site is deployed to [Vercel](https://vercel.com) and served at **https://vu-qc.com**.

Pushes to `main` trigger automatic deployments.
